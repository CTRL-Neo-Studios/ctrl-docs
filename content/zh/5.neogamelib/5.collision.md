# 碰撞

碰撞总线每帧（世界更新之后）检测一次重叠的碰撞体对，并通知双方对象上的
`ICollision` 组件。碰撞体是世界空间中的普通矩形；它们不需要精灵。

## 两种碰撞体

两者都在 `OnAwake` 中向 `NeoGame.ColliderBus` 注册，销毁时注销。

### NeoBoxCollider

一个由 `Offset` + `Size` 定义的矩形，相对于父变换：

```csharp
NeoObject wall = world.Instantiate("Wall", new Transform(new Vector2(200, 200)));
NeoBoxCollider wallCol = wall.AddComponent<NeoBoxCollider>();
wallCol.Size = new Vector2(64, 32);        // 以对象位置为中心
wallCol.Offset = new Vector2(0, -16);      // 平移盒子中心
```

| 成员 | 默认值 | 含义 |
|---|---|---|
| `Offset` | `(0, 0)` | 盒子中心相对位置的偏移 |
| `Size` | `(1, 1)` | 盒子尺寸 |
| `Bounds` | — | 世界空间 `Rectangle`，每次访问时计算 |

`Bounds` 跟随位置和缩放（负缩放会镜像偏移，尺寸保持绝对）。**旋转被忽略** ——
旋转后的碰撞体需要定向包围盒。

### NeoSpriteCollider

一种盒子碰撞体，其 `Bounds` 取自*同一对象*上的 `NeoSpriteRenderer` —— 无需手动
让 `Size` 与纹理保持同步：

```csharp
NeoObject player = world.Instantiate("Player");
player.AddComponent(new NeoSpriteRenderer(RenderBus, sheet));
player.AddComponent<NeoSpriteCollider>();   // 自动适配当前帧大小
```

它跟随动画帧（经 `SourceRectangle`）、精灵的锚点、缩放和位置。对象上没有渲染器
时，`Bounds` 为空。

## 做出反应：ICollision

在任何持有碰撞体的对象组件上实现 `ICollision`；当两者重叠时，总线会调用
碰撞对**双方**对象上的接口。

```csharp
public class HurtBox : NeoComponent, ICollision
{
    public void OnCollision(NeoBoxCollider other, NeoCollision collision)
    {
        // `other` 是你撞到的对象上的碰撞体
        // `collision` 是共享的碰撞对数据（双方拿到同一个实例）
    }
}

player.AddComponent<NeoSpriteCollider>();
player.AddComponent(new HurtBox());
```

- 碰撞对重叠的每一帧都会被调用（尚无进入/停留/离开跟踪）。
- 对象上的所有 `ICollision` 组件都会被调用，不只是第一个。
- 只为启用且挂载中的碰撞体触发回调。
- 增删这些组件即可增删碰撞行为 —— 无需继承碰撞体类。

### 碰撞对数据

`NeoCollision` 是一个纯数据容器：`A`、`B`（两个碰撞体）和 `Overlap`（两个边界
的重叠 `Rectangle` —— 推挤分离时有用）。双方收到同一个实例，所以你放在它上面
的状态在两侧共享。

## 检测何时运行

`NeoGame.Update` 先 tick 世界，然后才运行 `ColliderBus.Update()`。因此
`ICollision` 回调看到的是*本帧*更新后的位置，在 `OnUpdate` 中移动碰撞体当帧即
可生效。

`ColliderBus.Update()` 返回本帧的 `List<NeoCollision>`；总线也把它保存在
`ColliderBus.Collisions` 中。只有真正执行了回调的碰撞对才会被记录。

检测循环是 O(n^2) 配对测试，带逐帧缓存的边界（对当前规模够用；宽相是已知的
未来优化方向）。

## 世界碰撞分组 {#world-collision-groups}

默认情况下，未分组的世界与所有其他未分组的世界互相碰撞 —— 甚至跨世界。UI 放在
独立世界里的场景通常不希望 UI 与玩法互相碰撞。分组可以解决：

```csharp
WorldManager.GroupCollisions("ui", "ui");                          // ui 只与 ui 碰撞
WorldManager.GroupCollisions("gameplay", "players", "enemies");    // 三者共享检测
WorldManager.UngroupCollisions("ui");                              // 回到未分组池
```

规则：两个碰撞体都未分组，或同处一组时才会交互。未分组者永不与已分组者交互。

## 顺序与安全

回调是用户代码，可能在遍历中途做任何事（销毁对象、移除碰撞体、加载/卸载
世界）。遍历会连同缓存的边界与分组一起快照碰撞体，因此：

- 遍历中途被移除的碰撞体在本轮不再收到回调；
- 遍历中途新增的碰撞体从下一轮开始参与碰撞；
- 碰撞对的回调遵循遍历开始时捕获的分组关系。

## 与 NeoMover 的集成

`NeoMover`（见[系统](/8.systems#neomover)）在移动时对实时碰撞体列表做逐轴修正，
并用本帧的 `Collisions` 做着地检测。它需要同一对象上有自己的 `NeoBoxCollider`。
