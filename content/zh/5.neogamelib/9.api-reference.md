# API 参考

NeoGameLib 0.3.2 的所有公开类型，简明版。命名空间：

- `NeoGameLib`（根）
- `NeoGameLib.Common`
- `NeoGameLib.NeoGO`
- `NeoGameLib.NeoRendering`
- `NeoGameLib.NeoCollision`
- `NeoGameLib.NeoInput`
- `NeoGameLib.NeoUI` / `NeoGameLib.NeoUI.Elements`
- `NeoGameLib.NeoStorage`
- `NeoGameLib.FuckingEvents`（见[系统](/8.systems#eventbus-avoid)）

`virtual OnDrawBehind(SpriteBatch, in NeoSpriteDrawInfo)`、

`protected virtual OnFeatureAwake()`、`protected virtual OnFeatureDestroy()`。
要求同一对象上有 `NeoSpriteRenderer`（否则抛异常）。

### readonly struct NeoSpriteDrawInfo

`Scale`、`Effects`、`Depth`（全部只读）；
`void Draw(SpriteBatch, Texture2D, Color, Vector2 offset = default)`。

### class NeoOutlineFeature : NeoSpriteRenderFeature

`SurfaceFormat.Color` 纹理。
