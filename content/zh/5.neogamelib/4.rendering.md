# 渲染

渲染总线在单个 `SpriteBatch` 中绘制世界空间精灵和文本，可选通过一台或多台
摄像机。屏幕空间 UI 是独立的系统（见 [UI](/7.ui)）。

## 渲染总线

`NeoRenderBus` 维护三个自注册列表：精灵、文本和摄像机。每项在 `OnAwake` 中
通过传给其构造函数的总线注册自己，在 `OnDestroy` 时注销 —— 所以加载世界会把
它的渲染器和摄像机带进来，卸载则会带走它们。

### 绘制顺序

在一个世界通道内：

1. **精灵**，按 `Depth` 降序排序（`Depth` 越大 = 越靠后），相同 `Depth` 按注册
   顺序打破平局（先添加 = 先绘制 = 靠后）。
2. **文本**，同样的排序，总是绘制在精灵之后（文本位于世界上层）。

```csharp
// 两者 Depth 都是 0：后添加的绘制在上层
// 想不受添加顺序影响强制分层，就用 Depth：
backSprite.Depth = 1f;   // 靠后
frontSprite.Depth = 0f;  // 靠前
```

::callout{icon="i-lucide-info" color="primary"}
这里的 `Depth` 是排序键，不是 `SpriteBatch` 的 `layerDepth`：**越大 = 越靠后**。
所有项的默认值都是 0。
::

### 摄像机通道

- 每台**启用**的摄像机都按 `NeoCamera.Order`（小者先渲染）堆叠渲染世界，各自
  在自己的 `SpriteBatch` 通道中使用自己的视图矩阵。
- `NeoGame.OnDraw` 恰好触发一次，位于**主摄像机**的通道内。
- 没有启用的摄像机时，世界通道回退为单位矩阵通道（摄像机出现前的行为：
  (0,0) 即视口左上角）。
- `RenderBus.MainCamera` —— 按 Order（再按注册顺序）排列的第一台启用摄像机。
  驱动 `WorldToScreen`/`ScreenToWorld` 和 `OnDraw`。
- `RenderBus.HasAnyCamera` —— 是否存在任何启用的摄像机。
- `RenderBus.ViewMatrix` —— 主摄像机的矩阵，没有则为单位矩阵。

## NeoSpriteRenderer

按父对象的变换绘制一个 `Texture2D`（或其某一帧）。

```csharp
NeoObject obj = world.Instantiate("Crystal", new Transform(new Vector2(400, 300)));
NeoSpriteRenderer sprite = obj.AddComponent(new NeoSpriteRenderer(RenderBus, texture));
```

成员：

| 成员 | 默认值 | 含义 |
|---|---|---|
| `Texture` | `null` | 要绘制的纹理；`null` = 跳过 |
| `SourceRectangle` | `null` | 子矩形（动画帧）；`null` = 整个纹理 |
| `Color` | `White` | 色调 |
| `Depth` | `0` | 排序键，越大越靠后 |
| `Anchor` | `(0.5, 0.5)` | 原点，以帧尺寸的分数表示 |
| `Order` | 自动 | 注册顺序，深度平局时的决胜键（添加时由总线设置） |
| `Layer` | `1` | 摄像机裁剪位掩码（见下文） |

### 边界与屏幕检查

每次访问都根据父变换计算（`Bounds` 忽略旋转；`ScreenBounds` 则处理旋转）。

- `Bounds` —— 当前帧的世界空间 `Rectangle`（绝对、感知缩放、感知锚点）。
  `NeoSpriteCollider` 用的就是这个。
- `ScreenBounds` —— 帧经过主摄像机投影后的结果。
- `WithinViewportBounds` —— 是否完全位于视口内？
- `VisibleInViewportBounds` —— 是否有任何部分在视口内？用它来跳过绘制。
- `IsOverWindowBounds(Direction2D)` —— 该边是否越过视口边缘？
- `ContainsScreenPoint(Vector2 windowPixels)` —— 点是否位于绘制出的帧内（处理
  摄像机、旋转、缩放）。
- `IsCursorOnSprite()` —— 对当前鼠标位置调用 `ContainsScreenPoint`。

### 图层（摄像机裁剪）

`Layer` 是位掩码：只有当摄像机的 `CullingMask` 与精灵/文本的 `Layer` 至少共享
一个位（`(layer & mask) != 0`）时，摄像机才绘制它。

```csharp
sprite.Layer = 1 << 2;                     // 第 2 层
sprite.Layer = (1 << 3) | (1 << 7);        // 第 3 层和第 7 层

camera.CullingMask = 1;                    // 只渲染默认层
camera.CullingMask = (1 << 3) | (1 << 7);  // 只渲染第 3、7 层
camera.CullingMask = -1;                   // 全部（默认值）
```

### 负缩放 {#negative-scales}

负的 `Transform.Scale` 会镜像而非出错。总线把符号转换为 `SpriteEffects` 翻转并
保持绝对缩放值，所以：

```csharp
Vector2 scale = Transform.Scale;
scale.X = cursorX > Transform.Position.X ? MathF.Abs(scale.X) : -MathF.Abs(scale.X);
Transform.Scale = scale;   // 面向光标
```

边界保持为正的绝对矩形，碰撞体因此继续正常工作。

## NeoCamera

世界空间摄像机组件。挂载到对象上；摄像机每帧跟随对象的变换。

```csharp
NeoObject camObj = world.Instantiate("cam", new Transform(new Vector2(0, 0)));
NeoCamera cam = camObj.AddComponent(new NeoCamera(RenderBus)); // awake 时自注册
cam.Zoom = 2f;
```

| 成员 | 含义 |
|---|---|
| `Zoom` | 正数倍率；非法值（<= 0、NaN、Inf）会被静默拒绝 |
| `Order` | 越小越先渲染 |
| `CullingMask` | `Layer` 位掩码过滤器；默认 `-1` = 全部 |

视图矩阵为 `Translate(-pos) * Rotate(-rot) * Scale(zoom) * Translate(viewport/2)`：
摄像机的位置落在视口中心，旋转被反转，缩放作用于世界。

坐标转换（视口局部版本；总线会加上信箱偏移得到窗口像素版本）：

```csharp
Vector2 onScreen = RenderBus.WorldToScreen(new Vector2(100, 50));  // 窗口像素
Vector2 inWorld  = RenderBus.ScreenToWorld(Input.MousePosition);   // 世界坐标
```

`RenderBus.WorldToScreen`/`ScreenToWorld` 经由主摄像机转换（没有摄像机时为单位
矩阵），并计入信箱条偏移（见[系统](/8.systems#letterbox-viewport)）。

## NeoTextRenderer

文本与精灵类似：变换、颜色、深度、锚点、图层。

```csharp
NeoObject label = world.Instantiate("Score");
NeoTextRenderer text = label.AddComponent(new NeoTextRenderer(RenderBus, font));
text.Text = "Score: 0";
text.Anchor = Vector2.Zero;                    // 左上角，而不是居中
label.Transform.Position = new Vector2(20, 20);
```

成员与 `NeoSpriteRenderer` 对应：`Font`、`Text`、`Color`、`Depth`、`Anchor`、
`Order`、`Layer`。`Text` 为空或 `Font` 为 null 时跳过绘制。文本在所有精灵之后
绘制。

## NeoAnimator + NeoAnimation

动画 = 一列表格帧 + 每帧时长。动画器每 tick 设置精灵渲染器的
`SourceRectangle`，因此碰撞体、锚点和渲染特性自动跟随当前帧。

```csharp
NeoSpriteRenderer renderer = player.AddComponent(new NeoSpriteRenderer(RenderBus, sheet));
NeoAnimator animator = player.AddComponent<NeoAnimator>();   // 需要渲染器

NeoAnimation idle = new(new()
{
    new Rectangle(0,  0, 32, 32),
    new Rectangle(32, 0, 32, 32),
}, 0.2f);                    // 每帧 0.2 秒，循环

animator.Play(idle);

// 攻击 -> 回到待机
animator.OnAnimationFinished = () => animator.Play(idle);
```

`NeoAnimation.FromGrid` 按网格行走，免去逐帧手写边界：

```csharp
// 6x4 个 32x32 的格子，从左到右、从上到下
NeoAnimation run = NeoAnimation.FromGrid(new Point(6, 4), new Point(32, 32), 0.1f);

// 镜像行走，带间距和边距：
NeoAnimation padded = NeoAnimation.FromGrid(
    new Point(6, 4), new Point(32, 32), 0.1f,
    horizontal: Direction2D.Left,
    padding: new Point(2), margin: new Point(4));

// 逐列行走，播放一次，结束时清空精灵：
NeoAnimation vanish = NeoAnimation.FromGrid(
    new Point(4, 6), new Point(32, 32), 0.08f,
    loop: false, holdLastFrame: false);
```

| `NeoAnimation` | 含义 |
|---|---|
| `Frames` | 有序的 `List<Rectangle>` |
| `FrameDuration` | 每帧秒数 |
| `Loop` | 从第 0 帧重新开始（默认 true） |
| `HoldLastFrame` | 非循环时：保留最后一帧（true）或清空精灵（false） |

| `NeoAnimator` | 含义 |
|---|---|
| `Play(NeoAnimation)` | 从第 0 帧重新开始；对同一个实例再次 Play 是空操作；null/空动画抛异常 |
| `Stop()` | 停止播放（最后一帧保留） |
| `OnAnimationFinished` | 非循环动画越过最后一帧时触发；回调在结束画面应用之后运行，因此在其中调用 `Play` 总是生效 |
| `CurrentFrameIndex` | 当前帧 |
| 暂停 | `animator.Enabled = false` 暂停；重新启用即恢复 |

## 渲染特性

`NeoSpriteRenderFeature` 在同一对象的精灵周围绘制额外图层 —— 在精灵自己的渲染
通道中额外绘制，摄像机的裁剪、翻转和动画帧全部适用。

```csharp
public class ShadowFeature : NeoSpriteRenderFeature
{
    public override void OnDrawBehind(SpriteBatch sb, in NeoSpriteDrawInfo info)
    {
        info.Draw(sb, someTexture, Color.Black, new Vector2(4, 4)); // 例如偏移投影
    }
}

// 先挂载精灵渲染器
obj.AddComponent(new NeoSpriteRenderer(RenderBus, texture));
obj.AddComponent(new ShadowFeature());
```

每个精灵的绘制顺序：所有 `OnDrawBehind` → 精灵 → 所有 `OnDrawFront`（特性按
添加顺序）。`OnFeatureAwake`/`OnFeatureDestroy` 是设置与拆除的钩子；`Renderer`
给你精灵本身。禁用的特性不绘制。

`NeoSpriteDrawInfo` 携带已修正的绘制值（`Position`、`Origin`、`Scale`、
`Effects`、`Color`、`Depth` 等）。`info.Draw(sb, texture, color, offset)` 以精灵
的变换绘制纹理 —— 纹理必须与精灵纹理布局一致，因为源矩形相同。

### NeoOutlineFeature（内置）

精灵背后的纯色辉光：

```csharp
NeoOutlineFeature outline = obj.AddComponent(new NeoOutlineFeature
{
    Color = Color.Gold,
    Thickness = 2f,            // 世界像素
});
outline.Enabled = renderer.IsCursorOnSprite();  // 例如悬停辉光
```

把精灵的剪影复制 8 份，按 `Thickness` 朝 8 个方向偏移绘制在精灵背后。对动画
友好（跟随当前帧）。

## 自己动手绘制

`OnDraw` 在主摄像机的批处理内运行（没有摄像机时则是单位矩阵批处理）。自定义
屏幕空间绘制用 `OnDrawUI`。两者都接收共享的 `SpriteBatch`，已 Begin —— 直接画
即可。
