# 系统

配角阵容：计时器、内置移动处理器、文件存储、资源缓存、窗口/视口控制，以及两个
小工具。

## 计时器

`NeoTimer` 是独立的倒计时（不是组件）。运行时它向 `NeoGame.TimerBus` 注册，总线
在每帧末尾 tick 它；停止/结束时注销，因此空闲计时器零开销。

```csharp
NeoTimer invuln = new(0.5f);                       // 秒
invuln.OnFinished = () => { /* 无敌结束 */ };
invuln.Start();                                    // 运行时再次 Start 会从头重新开始

// 循环计时器：
spawnTimer.OnFinished = () => spawnTimer.Start();
```

| 成员 | 含义 |
|---|---|
| `Duration` | 秒（可设置） |
| `TimeLeft` | 剩余秒数（只读） |
| `IsRunning` / `IsPaused` | 状态 |
| `Start()` | 从完整时长（重新）开始；触发 `OnStart` |
| `Stop()` | 终止；`TimeLeft` 清零，触发 `OnStop` |
| `Pause()` / `Resume()` | 冻结/解冻倒计时；触发 `OnPause`/`OnResume` |
| `OnStart` / `OnStop` / `OnPause` / `OnResume` / `OnFinished` | 回调 |

::callout{icon="i-lucide-info" color="primary"}
虽然 `async`/`await` 在 MonoGame 中可用，但 `Task.Delay` 不会随游戏暂停，取消它
也很麻烦 —— `NeoTimer` 是暂停友好的替代方案。不要在已经持有该计时器的更新循环
里调用 `Start()`。
::

计时器回调可以安全地启动/停止/重启任何计时器（总线有快照）。tick 每帧最后
运行，在碰撞之后。

## NeoMover {#neomover}

一个移动组件，涵盖按键、`Move()`、lerp 平滑、重力、跳跃、着地检测和碰撞体
推挤。一切皆可选。

```csharp
NeoMover mover = player.AddComponent<NeoMover>();
mover.KeyLeft = Keys.A;
mover.KeyRight = Keys.D;
mover.KeyJump = Keys.Space;
mover.GroundComponentType = typeof(GroundTag);   // 需要同一对象上有 NeoBoxCollider
```

| 成员 | 默认值 | 含义 |
|---|---|---|
| `KeyUp` / `KeyDown` / `KeyLeft` / `KeyRight` / `KeyJump` | `null` | 绑定的按键；全为 null = 从不轮询按键（纯 `Move()` 控制） |
| `Speed` | 200 | 水平速度 px/s |
| `Gravity` | 2000 | px/s²；0 = 飞行 |
| `JumpVelocity` | 600 | 向上 px/s |
| `Omnidirectional` | true | false = 忽略上下输入（平台跳跃风格） |
| `UseLerp` | true | 平滑方向变化 |
| `LerpSnappiness` | 10 | 越大越灵敏 |
| `GroundComponentType` | `null` | 标记地面的组件类型（`typeof(GroundTag)`） |
| `Grounded` | — | 正接触带地面标签的对象（只读） |
| `CollisionWhitelist` / `CollisionBlacklist` | 空 | 穿透列表（见下文） |
| `Velocity` | — | 当前速度（只读；暴露给自定义碰撞修正使用） |

API：`Move(Vector2 direction)` 设置目标方向；`Jump()` 只在着地时跳；
`AddImpulse(Vector2)` 追加速度冲量；`AddToWhitelist<T>()` /
`RemoveFromWhitelist<T>()` / `AddToBlacklist<T>()` / `RemoveFromBlacklist<T>()`
用泛型管理列表。

### 实心 vs 穿透

mover 会把自身从重叠的碰撞体中推出来（逐轴，因此能沿墙滑动）。什么算实心：

| 列表 | 行为 |
|---|---|
| 两者皆空 | 一切都是实心的（默认） |
| 设置了白名单 | 只有白名单组件可穿透；其余实心 |
| 设置了黑名单 | 只有黑名单组件实心；其余穿透 |
| 两者皆设 | 白名单优先（白名单可穿透） |

```csharp
mover.CollisionWhitelist.Add(typeof(TriggerTag));   // 穿透触发器
mover.CollisionBlacklist.Add(typeof(SolidTag));     // 只有这些阻挡
```

要求：同一对象上有 `NeoBoxCollider`；着地需要 `GroundComponentType`。mover 还会
贡献下落速度；`Gravity = 0` 且无按键时，仅由 `Move()` 驱动。

## 文件存储

Tauri 风格的文件即对象存储，位于 `NeoGameLib.NeoStorage`。文件与文件夹缺失时
会在加载时创建。

### FileStore

```csharp
FileStore cfg = new FileStore(Path.Combine(Directory.GetCurrentDirectory(), "Data", "config.txt"));
cfg.Load();                       // 读取文件进缓冲区；缺失则创建文件/文件夹

string raw = cfg.Get();           // 整个缓冲区，\n 换行
List<string> lines = cfg.GetAsLines();  // 拆成行，\r\n 归一化，无末尾换行

cfg.Set("hello\nworld");          // 原样替换缓冲区
cfg.Set(new List<string> { "hello", "world" });  // 每项一行
cfg.Write();                      // 把缓冲区写入磁盘
```

### JsonStore

`FileStore` 子类，其缓冲区是 JSON 对象：

```csharp
JsonStore save = new JsonStore(Path.Combine(Directory.GetCurrentDirectory(), "Data", "save.json"));
save.Load();

save.Set("playerName", "Neo");
save.Set("gold", 420);

string name = save.Get<string>("playerName");   // "Neo"
int gold = save.Get<int>("gold");               // 420
int nope = save.Get<int>("missing");            // default(T)：0、null 等

save.Write();
```

- `Get<T>(key)` 对缺失的键返回 `default(T)`；`Set(key, object)`。
- `Options` 是 `JsonSerializerOptions`（默认 `IncludeFields = true`，这是必需项，
  否则 MonoGame 结构体如 `Vector2`/`Rectangle` —— 公开字段 —— 会序列化成 `{}`）。
  换成自己的以自定义。
- Load 把缓冲区解析为 `JsonObject`；Write 把它序列化回去。

### FolderStore

文件夹即存储：枚举顶层文件并为它们实例化存储对象。

```csharp
FolderStore data = new FolderStore(Path.Combine(Directory.GetCurrentDirectory(), "Data"));
data.Load();                       // 文件夹缺失则创建；列出顶层文件

JsonStore json = data.Instantiate<JsonStore>("save.json");  // 包装该文件
```

`Files` 列出顶层路径；暂无递归或通配符过滤。

## AssetManager

缓存的内容加载，以资源路径为键。经 `NeoGame.Assets`（或组件中的 `Assets` 简写）
访问。

```csharp
Texture2D bot = Assets.Load<Texture2D>("Sprites/bot");  // 加载一次，之后命中缓存
Assets.Unload("Sprites/bot");                            // 移除缓存，若 IDisposable 则释放
Assets.UnloadAll();
```

`Load<T>(path, forceLoad: false)` —— `forceLoad: true` 会重新读取并重新缓存。
它包装了游戏的 `ContentManager`，因此 `Content.RootDirectory` 仍然生效。

## 窗口 {#windowing}

`NeoGame` 提供窗口控制：

```csharp
NeoGame.Singleton.SetWindowMode(NeoWindowMode.Windowed);              // 有边框；恢复上次窗口尺寸
NeoGame.Singleton.SetWindowMode(NeoWindowMode.Fullscreen);            // 独占全屏
NeoGame.Singleton.SetWindowMode(NeoWindowMode.BorderlessFullscreen);  // 无边框，不切换显示模式
NeoWindowMode mode = NeoGame.Singleton.WindowMode;
```

请在游戏初始化**之后**调用 `SetWindowMode`。macOS 没有无边框全屏：在那里
`BorderlessFullscreen` 会变成 `Fullscreen`，`WindowMode` 报告 `Fullscreen`。

## 信箱视口 {#letterbox-viewport}

游戏视口不必与窗口一致。设置宽高比后，游戏绘制到窗口内居中的最大同比例盒子里，
周围留黑条：

```csharp
ViewportAspect = 16f / 9f;        // null（默认）= 填满整个窗口
LetterboxColor = Color.Black;     // 黑条
ClearColor = Color.CornflowerBlue; // 视口背景

Rectangle box = ViewportBounds;   // 游戏绘制的窗口像素矩形
```

- 摄像机、精灵、文本、画布、`OnDraw` 和 `OnDrawUI` 都在该盒子内工作。
- `Input.MousePosition` 仍是**窗口像素**；`RenderBus.ScreenToWorld`、
  `NeoCanvas.ScreenToCanvas` 和 `ContainsScreenPoint` 会扣除黑条偏移。
- 这不是虚拟分辨率 —— 一切仍按原生像素渲染。
- `GetScreenCenterCoords()` 返回视口中心。
- 视口在每次更新和绘制时重新应用，窗口缩放和模式切换始终正确。

`ReferenceResolution = 1280x720` 的画布在 16:9 视口中精确缩放，无需 `Match`
折中（见 [UI](/7.ui#scaling)）。

## NeoSingleton

你自己的单例，`NeoSingleton<T>` 提供 `Singleton` 属性，构造第二个实例时抛异常：

```csharp
public class GameSettings : NeoSingleton<GameSettings> { /* ... */ }
```

## Direction2D

`Direction2D`（`Left`、`Right`、`Up`、`Down`）带 `ToVector2()` 和 `Invert()`
扩展。`NeoSpriteRenderer.IsOverWindowBounds` 和 `NeoAnimation.FromGrid` 使用它。

## EventBus（避免使用） {#eventbus-avoid}

`NeoGameLib.FuckingEvents.EventBus` 是总线架构出现前的一个按类型分键的极简
发布/订阅辅助类。库中没有任何地方使用它，它自己的注释也警告这是技术债 ——
优先使用总线和组件。
