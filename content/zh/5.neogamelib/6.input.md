# 输入

NeoGameLib 提供键盘与鼠标的动作映射（`NeoInputMap`）、每帧刷新一次的总线，以及
面向鼠标的静态 `Input` 门面。如果你更喜欢，原生的 `Keyboard.GetState()` 依然
可用。

## 输入如何 tick

`NeoGame.Update` 每帧**最先**运行 `InputBus.Update()`，先于 UI、世界、碰撞和
计时器。因此输入映射携带的是本帧状态，供其后的一切使用。`IsPressed`/
`IsReleased` 是边沿触发：它们与上一帧的快照做比较。

## NeoInputMap

把按键/鼠标按钮映射为命名动作；按名字查询。

```csharp
NeoInputMap gameplay = new();

gameplay.AddDigital("jump", Keys.Space, Keys.W);            // 任一绑定的键触发它
gameplay.AddAxis("moveX", NeoAxisRange.Full, Keys.D, Keys.A); // 正向键、负向键
gameplay.AddMouseButton("fire", MouseButtons.Left);         // 与同动作的按键合并

gameplay.Subscribe();   // 注册到 NeoGame.InputBus（默认总线）

// 每帧，输入刷新之后：
gameplay.IsDown("jump");      // 按住
gameplay.IsPressed("jump");   // 本帧按下
gameplay.IsReleased("jump");  // 本帧松开
gameplay.GetAxis("moveX");    // -1..1
```

映射 API：

| 成员 | 含义 |
|---|---|
| `AddDigital(string action, params Keys[] keys)` | 任一绑定的键按住即触发动作 |
| `AddMouseButton(string action, params MouseButtons[] buttons)` | 任一绑定的按钮按住即触发；同一动作可同时绑定按键和按钮 |
| `AddAxis(string action, NeoAxisRange range, Keys? positive = null, Keys? negative = null)` | 按键对经轴范围映射 |
| `SetAction(string, params Keys[])` | 替换已有数字动作的按键；动作不存在则抛 `KeyNotFoundException` |
| `SetAction(string, NeoAxisRange, Keys? positive, Keys? negative)` | 替换轴动作 |
| `HasAction(string)` | 是否存在？ |
| `RemoveAction(string)` | 整体删除 |
| `Subscribe(NeoInputBus bus = null, bool dedupe = true)` | 注册以逐帧刷新（默认总线 = `NeoGame.Singleton.InputBus`） |
| `Unsubscribe(NeoInputBus bus = null, bool dedupe = true)` | 注销 |

::callout{icon="i-lucide-alert-triangle" color="warning"}
**查询从未添加过的动作会抛异常**（`KeyNotFoundException`）—— 拼写错误是 bug，
不是静默的零。查询*已映射*但尚未经历第一次刷新的动作，返回种子默认值
（false / 0）。
::

### 轴范围

`NeoAxisRange` 把按键对映射为浮点数：

| 范围 | 正向键 | 负向键 | 都未按 |
|---|---|---|---|
| `Positive` | 1 | 0 | 0 |
| `Negative` | 0 | -1 | 0 |
| `Full` | 1 | -1 | 0 |
| `PositiveInverted` | 0 | 1 | 1 |
| `NegativeInverted` | -1 | 0 | -1 |
| `FullInverted` | -1 | 1 | 0 |

## Input 门面

`NeoGameLib.NeoInput.Input` 是一个静态简写，背后是一张隐藏映射表，把五个鼠标
按钮绑定为动作：

```csharp
Input.LeftMouseButton.IsDown();
Input.LeftMouseButton.IsPressed();
Input.LeftMouseButton.IsReleased();
Input.RightMouseButton.IsDown();
Input.MiddleMouseButton.IsDown();
Input.XButton1.IsDown();
Input.XButton2.IsDown();

Input.MousePosition;   // Vector2，窗口像素（不是世界坐标，也不是 UI 单位）
```

- `MousePosition` 的单位是**窗口像素**；转世界空间用 `RenderBus.ScreenToWorld`，
  转 UI 空间用 `NeoCanvas.ScreenToCanvas`。
- 门面映射表在第一次使用时构建并注册自己；`NeoGame` 保证它在每帧输入刷新前
  存在。在游戏初始化其总线之前查询会抛异常。

## 总线本身

`NeoInputBus` 保存已注册的映射表，每帧从单个键盘/鼠标快照刷新它们。

- `Update()` —— 从实时的 `Keyboard.GetState()`/`Mouse.GetState()` 刷新（由
  NeoGame 调用）。
- `Update(KeyboardState current)` / `Update(KeyboardState, MouseState)` —— 从给定
  快照刷新（模拟输入时有用）。
- `ListenInput()` —— 本帧按住的按键。

你很少需要直接操作总线；`Subscribe()` 就够了。及时注销不再需要的映射表可减少
每帧开销。

## 原生访问

一次性读取用原生 MonoGame 即可，无需注册：

```csharp
KeyboardState kb = Keyboard.GetState();
if (kb.IsKeyDown(Keys.Escape)) Exit();
```

当你想要可重绑定、命名、边沿触发的动作时，优先使用 `NeoInputMap`。
