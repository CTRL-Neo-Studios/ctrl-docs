# 游戏对象

这个库的核心：世界容纳对象，对象容纳组件，组件容纳你的全部逻辑。

```csharp
NeoWorld world = WorldManager.CreateWorld("level1", w =>
{
    NeoObject player = w.Instantiate("Player", new Transform(new Vector2(100, 100)));
    player.AddComponent(new NeoSpriteRenderer(RenderBus, sheet));
});
WorldManager.Load("level1");
```

## NeoGame

`NeoGame` 是你的 `Game` 子类。它在 `Initialize` 中（先于你的任何内容加载）
创建所有总线和管理器，按固定顺序驱动它们 tick，并绘制世界/UI 通道。

- `NeoGame.Singleton` —— 静态实例（由第一个构造的 `NeoGame` 设置）。
- `NeoGame<T>` —— 用于类型化单例：`public class MyGame : NeoGame<MyGame>`
  会给你类型为 `MyGame` 的 `MyGame.Singleton`。

管理器属性可通过 `NeoGame.Singleton` 在任何地方访问，也可作为任何
`NeoComponent` 内部的简写（它们只在游戏初始化前为 `null`，而初始化先于
你的任何钩子运行）：

| 属性 | 类型 |
|---|---|
| `RenderBus` | `NeoRenderBus` |
| `ColliderBus` | `NeoColliderBus` |
| `TimerBus` | `NeoTimerBus` |
| `InputBus` | `NeoInputBus` |
| `UIBus` | `NeoUIBus` |
| `WorldManager` | `WorldManager` |
| `Assets` | `AssetManager` |
| `GraphicsDeviceManager` | `GraphicsDeviceManager` |
| `GraphicsViewport` | `Viewport`（图形设备视口） |

窗口与视口属性（`ViewportAspect`、`ClearColor`、`SetWindowMode` 等）记录在
[系统](/8.systems#windowing)。

## 世界

`NeoWorld` 是一个对象容器，加载期间每帧 tick。

### 注册表模型

`WorldManager` 维护一个命名世界注册表。你**创建**（create）一次世界（可选
带构建器），然后**加载**（load）它以构建并运行，**卸载**（unload）它以销毁
其对象。

- 对象在 **Load** 时构建，而不是 Create 时。构建器回调每次加载都会运行。
- 卸载会销毁世界中的每个对象。世界仍留在注册表中，可以再次加载（从头重新
  运行构建器）。
- 任意数量的世界可以同时加载；每个世界独立 tick。
- 没有世界状态持久化：这是注册表，不是存档系统。如果世界需要初始状态，请
  放在构建器里。

```csharp
WorldManager.CreateWorld("ui", w => { /* 构建 HUD 对象 */ });
WorldManager.CreateWorld("level1", w => { /* 构建玩法对象 */ });

WorldManager.Load("ui");
WorldManager.Load("level1");

NeoWorld hud = WorldManager.GetWorld("ui");          // 也可以写成：WorldManager["ui"]
NeoObject obj = hud.FindObjectByComponent<HudManager>();

WorldManager.Unload("level1");   // 销毁 level1 中的每个对象
WorldManager.Load("level1");     // 从构建器重新构建
WorldManager.RenameWorld("ui", "hud");
WorldManager.UnloadAll();        // 卸载一切；注册信息保留
```

WorldManager API：

| 成员 | 含义 |
|---|---|
| `CreateWorld(string name, Action<NeoWorld> build = null)` | 注册一个新世界；名字已存在则抛异常 |
| `CreateWorld(NeoWorld world, Action<NeoWorld> build = null)` | 注册一个已有实例（不推荐 —— 见下文） |
| `Load(string name)` | 运行构建器并开始 tick；已加载则为空操作 |
| `Unload(string name)` | 停止 tick 并销毁所有对象；世界仍留在注册表 |
| `UnloadAll()` | 卸载所有已加载世界 |
| `GetWorld(name)` / `this[name]` / `TryGetWorld(name, out w)` | 查找已注册的世界 |
| `IsLoaded(name)` | 它是否正在 tick？ |
| `RenameWorld(name, newName)` | 重命名注册表条目（保留碰撞分组） |
| `LoadedWorlds` | 按加载顺序排列的已加载世界 |
| `GroupCollisions(group, params string[] worlds)` | 见[碰撞](/5.collision#world-collision-groups) |
| `UngroupCollisions(world)` | 移出任何分组 |

::callout{icon="i-lucide-info" color="primary"}
手动创建世界再注册（而不是用名字重载）是允许的，但不推荐：如果你在构建器
之外实例化了对象，一次卸载/重新加载之后它们就会消失。
::

## NeoObject

对象 = 身份 + 变换 + 组件列表。把行为放进组件，而不是放进对象子类。

```csharp
NeoObject player = world.Instantiate("Player", new Transform(new Vector2(100, 100)));
player.AddComponent<PlayerController>();
```

### 创建对象

`NeoWorld.Instantiate` 重载：

- `Instantiate(string name)` —— 默认变换 (0,0)，缩放 1
- `Instantiate(string name, Vector2 position)`
- `Instantiate(string name, Transform transform)`
- `Instantiate<T>(T obj)` —— 保留对象的当前变换
- `Instantiate<T>(T obj, Vector2 position)` —— 覆盖位置
- `Instantiate<T>(T obj, Transform transform)` —— 覆盖整个变换

`Instantiate` 会为对象赋值 `World`，把它加入世界列表，并触发
`OnInstantiate()` —— 这是 `NeoObject` 上的虚方法，先于任何组件的 `OnAwake`
运行，也是推荐的添加组件的位置（而非构造函数）。

### 销毁对象

- `obj.DestroyToQueue()` —— 常规路径。进入队列；对象及其组件在当前世界 tick
  结束时被销毁。队列清空时组件 `OnDestroy` 立即运行。
- `world.Destroy(obj)` —— 同样的队列，从世界一侧调用。
- `obj.DestroyImmediate()` —— 立即销毁，可在回调中途执行。主要用于内部；
  除非需要即刻拆除，否则优先用队列。

`DestroyImmediate` 将对象标记为已销毁，并按添加顺序的逆序对每个组件运行一次
`OnDestroy`。

### 组件

```csharp
public T AddComponent<T>() where T : NeoComponent, new();
public T AddComponent<T>(T component) where T : NeoComponent;
public T GetComponent<T>() where T : NeoComponent;      // 不存在则返回 null
public bool TryGetComponent<T>(out T component);
public bool HasComponent<T>();
public bool HasComponent(Type type);
public bool RemoveComponent(NeoComponent component);
public bool RemoveComponent<T>();
```

`AddComponent` 立即触发 `OnAwake`。刚添加的组件立即可被 `GetComponent` 看到，
但在它之后添加的组件尚未 awake。

`Components` 是原始列表。用 `PassSnapshot` 遍历它（见下文）。

## NeoComponent

组件的生命周期：

1. **`OnAwake`** —— 一次，在 `AddComponent` 挂载组件时立即触发。此时
   `ParentObject`、`ParentTransform`、`ParentWorld` 均已就绪。内置组件在这里
   向总线注册；你自己需要父对象的初始化也放在这里。
2. **`OnStart`** —— 一次，在启用状态下的第一次 tick 触发。此时整个组件列表
   已注册完毕，`GetComponent` 能看到所有组件。
3. **`OnUpdate(GameTime)`** —— 启用期间每个世界 tick。
4. **`OnDestroy`** —— 一次，在组件被移除或对象死亡时触发。调用期间父对象仍然
   挂载 —— 清理逻辑放在这里。

```csharp
public class PlayerController : NeoComponent
{
    private NeoSpriteRenderer _renderer;

    public override void OnAwake()
    {
        _renderer = ParentObject.GetComponent<NeoSpriteRenderer>();
    }

    public override void OnUpdate(GameTime gameTime)
    {
        float speed = 200f * (float)gameTime.ElapsedGameTime.TotalSeconds;
        if (Input.LeftMouseButton.IsDown())
            ParentTransform.Move(new Vector2(1, 0), gameTime);
    }
}
```

组件成员：

| 成员 | 含义 |
|---|---|
| `ParentObject` / `ParentTransform` / `ParentWorld` | 所属对象及其相关内容 |
| `Enabled` | 关闭 = 跳过 `OnStart`/`OnUpdate`（默认开启） |
| `IsAttached` | 挂载在存活对象上时为 true；移除/销毁后为 false |
| `HasRanOnStart` | `OnStart` 是否已触发？ |
| `Assets`、`WorldManager`、`RenderBus`、`ColliderBus`、`TimerBus`、`InputBus` | 管理器简写 |

对于使用这些总线的组件，`Enabled = false` 同样会阻止碰撞回调和渲染特性。

## Transform

`Transform` 是世界空间中简单的位置/旋转/缩放。

| 成员 | 含义 |
|---|---|
| `Position : Vector2` | 世界位置 |
| `Rotation : float` | 弧度 |
| `Scale : Vector2` | 逐轴缩放；负值会镜像（见[渲染](/4.rendering#negative-scales)） |
| `Up` / `Down` / `Right` / `Left` | 按 `Rotation` 旋转后的单位向量 |
| `Move(Vector2 direction, GameTime)` | `Position += direction * dt` |
| `FaceTowards(Direction2D side, Vector2/Transform/NeoObject target)` | 旋转使指定的一侧指向目标；距离为零时为空操作 |

`NeoObject.Transform` 的 setter 逐字段复制 `Position`/`Rotation`/`Scale`。

## 查询

`NeoWorld` 的查找函数（均为线性扫描）：

- `FindObjectByName(name)` —— 精确区分大小写，返回第一个匹配；`FindObjectsByName` 返回全部
- `FindObjectByComponent<T>()` / `FindObjectsByComponent<T>()`
- `FindObjectByHashCode(int)`
- `FindComponent<T>()` —— `FindObjectByComponent<T>()?.GetComponent<T>()` 的简写
- `FindComponents<T>()`
- 以上每个都有 `Try...` 变体，找不到时返回 `false`/`null` 而不是 `null`

`NeoObject` 同样有 `HasComponent`、`GetComponent`、`TryGetComponent`。

## 自己遍历：PassSnapshot {#iterating-yourself-passsnapshot}

库中的每个循环都在遍历列表的租用副本，因此在遍历途中修改是安全的。当你自己
遍历对象或组件时，也这样做：

```csharp
using PassSnapshot<NeoObject> objects = new(world.Objects);
for (int i = 0; i < objects.Count; i++)
{
    NeoObject obj = objects[i];
    if (obj.IsDestroyed) continue;   // 在本轮遍历中被销毁
    // ... 在这里可以任意生成或销毁对象
}
```

规则：

- `using` 是必须的 —— 它把租用的数组归还给池。
- 项目被销毁后**不会**从快照中移除；每次迭代都要检查 `IsDestroyed`（对象）/
  `IsAttached`（组件）。
- 快照是单帧副本；修改立即作用于真实列表，下一帧再反映到快照。
- 支持嵌套；每个 `PassSnapshot` 租用自己的数组。
- 不要跨帧缓存快照。
- 空列表也会租用 0 长度数组；无妨。

它位于 `NeoGameLib.Common`。

## 完整示例

```csharp
public class MyGame : NeoGame
{
    protected override void OnLoadContent(ContentManager cm)
    {
        Texture2D sheet = cm.Load<Texture2D>("sprites/sheet");

        WorldManager.CreateWorld("level1", w =>
        {
            NeoObject player = w.Instantiate("Player", new Transform(new Vector2(320, 240)));
            player.AddComponent(new NeoSpriteRenderer(RenderBus, sheet));
            player.AddComponent<PlayerController>();
            player.AddComponent(new NeoBoxCollider { Size = new Vector2(32, 32) });
        });

        WorldManager.Load("level1");
    }
}

public class PlayerController : NeoComponent
{
    public override void OnUpdate(GameTime gameTime)
    {
        Vector2 input = Vector2.Zero;
        KeyboardState kb = Keyboard.GetState();
        if (kb.IsKeyDown(Keys.A)) input.X -= 1;
        if (kb.IsKeyDown(Keys.D)) input.X += 1;
        if (kb.IsKeyDown(Keys.W)) input.Y -= 1;
        if (kb.IsKeyDown(Keys.S)) input.Y += 1;

        ParentTransform.Move(input, gameTime);
    }
}
```

::callout{icon="i-lucide-info" color="primary"}
原生的 `Keyboard.GetState()` 完全可用。想要可重绑定、结构化的输入，见
[输入](/6.input)（`NeoInputMap`）；想要重力/跳跃/碰撞体解析，见
[系统](/8.systems#neomover) 中的 `NeoMover`。
::
